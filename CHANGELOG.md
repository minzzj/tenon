## [Unreleased] — v0.1.0

### Added

- Repository foundation: bilingual README, CC BY-NC-SA 4.0 license (English canonical + official Chinese translation), commercial-use policy, contributing and security policies.
- Documentation skeleton: product definition, assumptions & non-coverage list, manual, test method, deliverable checklist.
