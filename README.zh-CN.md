## 它是什么

| 场景 | 榫卯怎么做 |
|---|---|
| 语音控制电脑 | 说「打开记事本」「把音量调到 40」「回家模式」——本地语音识别 + AI 规划 + 电脑执行器，执行留痕 |
| 手机电脑协同 | 手机录音上传电脑识别、手机屏幕内容上报电脑、手机可看电脑端全天录音/屏幕记录、手机一键更新 |
| 电脑自动化 / RPA | 执行器（node-agent）接单执行程序、音量、场景、文件、打印（不可逆操作需确认），每步有证据 |
| 智能家居 / 物联网 | Home Assistant / MQTT / SSDP 设备接入与状态控制 |
| 全天记录与总结 | 手机 24h 环境录音、电脑屏幕记录（5 秒取帧、画面变化才上传）、转写、按设备分节 AI 总结，MD/DOCX/PDF |
| 隐私与审计 | 数据只落本机；哈希链事件账本；敏感内容过滤；审计可导出 |

## 快速开始

- 桌面：`desktop/release/TenonSuperTerminal-0.6.12-portable.exe`
- 安卓：`public/download/tenon-android-0.6.12-debug.apk`（二维码在 `public/download/`）
- 源码：`npm install && npm start`（本地中枢 http://127.0.0.1:7410），`npm test` 跑测试

详细步骤：[使用手册](docs/使用手册-V5.md)；安全边界：[SECURITY.md](SECURITY.md)；审计证据：`_internal/audit/`。

## 架构

- 中枢 `server/`：Node.js 零框架，7410，本地 HTTP/SSE/JSONL 账本
- 执行器 `node-agent/`：能力注册、心跳、接单执行
- 桌面 `desktop/`：Electron 单程序，启动中枢+执行器+屏幕采集+悬浮球
- 手机 `android/`：语音 / 24h / 屏幕采集 / 记录 / 文档 / 一键更新
- 语音：本地 FunASR Paraformer-large + 常驻转写/OCR worker；AI 规划 DeepSeek（可配置）
- 数据：全部本地 `data/`（便携版 `%APPDATA%\tenon-super-terminal\data`）

## 为什么叫「榫卯」

榫卯是中国传统木工的连接方式：不靠钉子，靠结构互相咬合。项目想让设备、程序、AI 像榫卯一样严丝合缝地连接，并且每一步都能查谁批准、办到哪、数据去哪——中文名保留「榫卯」，英文名 **Tenon**（榫头）。
