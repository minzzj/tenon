## 4. 未验证 / 边界（诚实清单）

- Android real-device install/interaction not verified (no device attached)
- voice input uses browser SpeechRecognition; in headless verification it degrades to text (as designed); real microphone not exercised
- AI intent ran on rule-engine fallback because DEEPSEEK_API_KEY was not set in this shell; DeepSeek path covered by unit tests
- home devices TV/speaker/light are simulated (simulated:true); only the Windows desktop and Android app are real devices
- handoff from a real phone's physical tilt was simulated via injected deviceorientation events in headless Chrome; Android sensor code compiles but is not device-tested

## 5. 复现方式

```powershell
# 1) 启动中枢（v2.1 自动挂载 link/assets/things/enterprise/super 共 60 条路由）
node server/start.js
# 2) 启动桌面 Agent（注册 app.launch/url.open/media.show/handoff.show/app.list）
$env:TENON_V2="1"; node node-agent/agent.js
# 3) 打开超级终端（浏览器访问 http://127.0.0.1:7410/ 默认进入 #/super）
# 4) 手机访问 http://<电脑局域网IP>:7410/m → 点「甩到电脑」或把手机往前一倾
# 5) 复跑验收：npm test && npm run test:modules && npm run test:e2e && npm run test:v2
```

> 说明：AI 意图在没有 `DEEPSEEK_API_KEY` 时走规则引擎（本次验收即此模式）；配置 key 后自动切换 DeepSeek。家庭电视/音箱/灯为模拟设备（`simulated:true`），只有 Windows 电脑与 Android App 是真实设备。
