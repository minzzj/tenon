## 4. 性能与稳定性实测

- 断开设备 → 3 条引用任务降级：**275ms**（验收线 10s）。
- 图片能力：10 个输入（9 正常 + 1 损坏）→ 9 成功 1 失败，单个任务全链路（草案→执行→回传）约 **1.5s**。
- 强杀重启：账本重放恢复 < 1s；无重复执行（比对 task.started / task.succeeded 计数）。
- 事件账本：某次故障演练后 520 条事件，seq 连续、prev 哈希链完整、缺口显式标记。
