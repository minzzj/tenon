# 榫卯超级终端 · 使用手册（V5）

> 功能名速查：一键唤醒=免唤醒词快捷录音；语音唤醒=喊「榫卯/小榫」；24 小时录制=全天环境录音；屏幕内容采集=屏幕记录/截图 OCR；记录=笔记+全天录音+屏幕记录；文档=AI 总结/日报；悬浮球=桌面快捷球；执行器=电脑自动化执行。
> 更多别名与搜索词见 [项目别名与搜索关键词](项目别名与搜索关键词.md)。

> 适用版本 **v0.6.0（2026-10-30 晚）**。V5 在 V4「一个桌面程序」的基础上升级为：**会记（语音笔记）、会总结（结构化总结 + Markdown/DOCX/PDF 文档）、会提醒、能连真实家居设备**，手机 App 同步到 0.6。
>
> 本手册按实际界面与接口写；未真机 / 无真实设备的项目在 §14「已知边界」如实标注。雷鸟 AI 眼镜的官方功能对照见 [雷鸟AI眼镜对照-V5.md](雷鸟AI眼镜对照-V5.md)。

## 1. 这次新增了什么

| 能力 | 你会得到 |
|---|---|
| 语音笔记 | 说「记一下：…」→ 直接写成本地笔记（JSONL + Markdown），可搜索 / 编辑 / 删除 / 导出 |
| 真正的总结 | 说「总结今天」→ DeepSeek 输出「摘要 / 重点 / 待办 / 回顾 / 日记」，并生成 **Markdown / DOCX / PDF** 文档 |
| 文档中心 | 文档页可预览、下载三种格式、删除；手机 App 可下载并分享 |
| 提醒 | 语音或设置页创建（一次性 / 每天）；到点账本 + 网页 SSE + 电脑 TTS 播报 + Windows 系统通知 + 手机通知 |
| 手机 0.6 | 5 页签：首页 / 记录 / 提醒 / 文档 / 设置；笔记/提醒/文档同步、本地通知、文档分享、IoT 控制 |
| 真正物联 | Home Assistant REST / MQTT / SSDP 接入 → 统一设备列表 → 网页、语音、手机控制；大品牌设备经 HA/MQTT 桥接 |
| 今日看板 | 首页一屏看：下一个提醒、今日笔记数、今日总结与下载、今日屏幕采集数 |

## 2. 环境与前置

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位），可用麦克风 |
| 桌面程序 | 沿用 V4：单文件便携版 / 桌面快捷方式 / `启动超级终端.cmd` / 开发模式（详见 [使用手册 V4](使用手册-V4.md)） |
| Node.js | `启动超级终端.cmd` 与开发模式需要 Node.js >= 22；单文件便携版不需要另装 |
| Python 3 | 本地语音识别（FunASR）与屏幕 OCR 的 worker 需要本机 Python 环境 |
| 手机 | Android 8.0+，与电脑同一 WiFi |
| 物联（可选） | 有 Home Assistant 实例（REST）或 MQTT Broker 时，可接入真实设备；大品牌设备需先接入 HA / MQTT 网关 |
| AI（可选） | `DEEPSEEK_API_KEY`：总结与智能规划用；未配置时本地降级 |

## 3. 启动与退出（沿用 V4）

1. 双击单文件便携版 `desktop/release/TenonSuperTerminal-0.6.0-portable.exe`（约 128 MB，已构建）或桌面「榫卯超级终端」快捷方式；
2. 仓库内运行：双击 `启动超级终端.cmd`；开发模式：`cd desktop && npm start`；
3. 旧完整控制台保留在 `http://127.0.0.1:7410/legacy`；
4. **关闭窗口 = 收到托盘**；右键托盘可暂停监听 / 暂停采集 / 现在生成今日总结 / 提醒 / 开机自启 / 退出。

## 4. 首页与今日看板（5 页签）

V5 界面底部为 **5 个页签**：**首页 / 记录 / 提醒 / 文档 / 设置**。

首页从上到下：

1. 顶部状态行（在线圆点、语音与采集状态、设置齿轮）；
2. 大麦克风 + 单行实时字幕（同一句只显示一条）+ 文字命令输入；
3. 结果卡（AI 回复、执行步骤、待确认按钮、provider/耗时）；
4. **今日看板**（4 块）：
   - **下一个提醒**：最近一条待触发提醒；点它去提醒页；
   - **今日笔记**：今日笔记条数；点它去记录页；
   - **今日总结**：未生成时点「生成」；生成后可下载 **MD / DOCX / PDF**；
   - **今日屏幕采集**：今日屏幕文字条数（只存本机）。

## 5. 说话就能记、就能总结、就能提醒

### 5.1 记笔记

- 说：「**记一下：明天下午三点和供应商开会，带上样品**」→ 自动生成一条笔记并落盘；
- 也支持「记录…」「帮我记…」；
- 笔记保存位置：`data/notes/YYYY-MM-DD.jsonl`（数据）与 `data/notes/md/`（Markdown 文件）；
- 笔记写入账本（`note.*`），可追溯。

### 5.2 总结

- 说：「**总结今天**」/「今天都做了什么？」→ 生成结构化总结；
- 也可在记录页点「**AI 总结**」，或在首页看板点「生成」；
- 输出固定五部分：**摘要 / 重点 / 待办 / 回顾 / 日记**（DeepSeek；无 key 时本地降级）；
- 同时生成三种文档：**Markdown（.md）/ Word（.docx）/ PDF（.pdf）**，在「文档」页下载。

### 5.3 提醒

- 说：「**提醒我 21:30 开会**」→ 一次性提醒；
- 说：「**每天 8 点提醒我吃药**」→ 每天提醒；
- 说：「**1 分钟后提醒我喝水**」→ 相对时间提醒；
- 也可在「提醒」页手动创建（内容 + 时间 + 一次性/每天）；
- 到点会：写账本 `reminder.fired` → 网页 SSE 推送 → 电脑 TTS 语音播报 → Windows 系统通知（桌面程序/节点在线时）→ 手机 App 本地通知（推送轮询/后台任务）；
- 提醒完成后点「完成」/「确认」，同一提醒不会重复触发。

### 5.4 执行命令（沿用 V4）

「打开记事本」「把音量调到 60」「回家模式」等：由执行器规划并执行；不可逆动作需确认；全部写审计。

## 6. 记录页

- 顶部搜索框：按内容搜索笔记；可按日期筛选；
- 「**AI 总结**」：把当前记录变成结构化总结（并生成文档）；
- 笔记列表：时间、来源（语音/文字）、摘要；点开看详情；
- 详情里可：编辑、删除、**下载 MD / DOCX / PDF**；
- 手机 App「记录」页同样可看、可总结、可删除。

## 7. 提醒页

- 新建：内容 + 时间（`YYYY-MM-DD HH:mm`）+ 一次性 / 每天；
- 列表显示状态：待触发 / 已逾期 / 已完成；
- 操作：完成、删除；
- 到点表现见 §5.3；手机 App「提醒」页可看到同一批提醒并收到本地通知。

## 8. 文档页

- 列表：标题、类型、时间、大小；可预览；
- 「**生成今日总结**」：立即生成今天的结构化总结 + 三种文档；
- 每个文档可下载 **MD / DOCX / PDF**、删除；
- 手机 App「文档」页可拉取同一列表、下载到本机并**分享到微信/QQ/邮件**（FileProvider + 系统分享）；
- 文件存放：`data/documents/`。

## 9. 设置页

| 分组 | 内容 |
|---|---|
| 语音与采集 | 常驻监听、唤醒词、TTS、每晚总结时间、屏幕采集间隔（沿用 V4） |
| **物联（IoT）** | **Home Assistant**：地址（如 `http://192.168.1.10:8123`）+ 长期访问令牌 → 测试连接 → 拉取实体 → 导入设备；**MQTT**：Broker 地址/端口/用户名/密码 + HA discovery 开关 → 连接 → 发现设备；**SSDP**：局域网扫描 → 列出可发现设备 |
| 执行器 | 动作白名单、不可逆确认、审计（沿用 V4） |
| DeepSeek | 只读状态（是否配置 key） |
| 存储与隐私 | 数据保留、关于/隐私说明 |

> 物联接入后，设备会出现在统一设备列表：网页可点按钮控制，语音可说「打开客厅的灯」，手机 App「设置 → IoT 与设备」可控制。

## 10. 手机 APK 0.6

### 10.1 安装

- 文件：`public/download/tenon-android-0.6.0-debug.apk`（2.77 MB，debug 签名，仅体验用）；
- 传到手机安装（允许「未知来源」）；
- **未真机实测**：以构建 + lint + 静态校验为准，安装与通知/分享需在手机上确认。

### 10.2 权限

| 权限 | 用途 |
|---|---|
| 麦克风（RECORD_AUDIO） | 录音送电脑识别 |
| 通知（POST_NOTIFICATIONS） | 提醒本地通知 |
| 屏幕采集（MediaProjection / 前台服务） | 屏幕内容定时上报 |
| 网络 / WiFi | 连接电脑中枢 |

### 10.3 5 个页签

- **首页**：大麦克风（录音送电脑识别并执行）、单行字幕、今日摘要；
- **记录**：笔记列表/搜索/详情/删除/「总结这段」；
- **提醒**：列表、新建、完成；前台 30 秒轮询 + 后台 WorkManager 兜底，到点弹本地通知；
- **文档**：文档列表、生成今日总结、下载 MD/DOCX/PDF、系统分享；
- **设置**：中枢地址/令牌、语音管家、提醒与通知、笔记与文档、IoT、本机清理、关于/隐私。

### 10.4 配置

在手机「设置 → 中枢连接」填电脑地址（`http://电脑IP:7410`）与操作令牌（电脑 `data/secrets.json` 的 `operatorToken`）；手机与电脑同一 WiFi。

## 11. 真正物联：怎么接真实设备

V5 支持三种标准接入方式（**不直连厂商云**）：

| 方式 | 适合 | 步骤 |
|---|---|---|
| **Home Assistant REST** | 小米/华为/苹果/Aqara/涂鸦等大品牌（先接入 HA） | HA 地址 + 长期令牌 → 测试 → 拉实体 → 选设备「导入」 |
| **MQTT（含 HA discovery）** | 自建 MQTT 设备、HA MQTT 集成 | 填 Broker 地址/端口/账号密码 → 连接 → 自动发现/手动导入 |
| **SSDP 局域网发现** | 支持 UPnP/SSDP 的设备 | 点扫描 → 列表 → 仅可查看（是否可控取决于设备 UPnP 实现） |

- 导入后进入统一设备列表，可网页点控、语音说「打开…」、手机 App 控制；
- 所有控制写账本 `iot.*`，可审计；
- **诚实边界**：本轮不做厂商账号授权直连；没有真实家居设备时用本地桩验证（见交付物清单）。

## 12. 隐私与数据

| 数据 | 位置 | 上传 |
|---|---|---|
| 笔记 | `data/notes/`（JSONL + Markdown） | 不上传 |
| 提醒 | `data/reminders/` | 不上传 |
| 文档 | `data/documents/`（MD/DOCX/PDF） | 不上传；生成时把当天文本发 DeepSeek |
| 物联配置 | `data/iot/`（HA 地址/令牌、MQTT 凭据） | 只在本机使用 |
| 语音/屏幕文字/日记 | `data/voice/`、`data/screen/` | 只存本机；仅总结文本发 DeepSeek |

## 13. 常见问题（FAQ）

**Q：说「记一下」没有生成笔记？**
1. 确认首页显示「正在聆听」；
2. 说话以「记一下」「记录」「帮我记」开头；也可直接在记录页新建；
3. 语音识别异常时用文字输入兜底。

**Q：总结生成失败 / 内容空泛？**
1. 检查是否配置 `DEEPSEEK_API_KEY`；未配置会本地降级（内容较简）；
2. 当天没有任何笔记/语音/屏幕内容时，总结会提示信息不足；
3. 在记录页或首页看板点「生成」重试。

**Q：文档下载不了？**
1. 先确认文档已生成（文档页列表有记录）；
2. 下载格式可选 MD / DOCX / PDF；
3. 手机端需给 App 存储权限（下载到 App 私有目录再分享）。

**Q：提醒没响？**
1. 桌面程序需在运行（托盘常驻）、电脑通知未被系统勿扰模式拦截；
2. 手机端需允许通知权限（Android 13+ 会请求）；
3. 提醒时间已过会显示「已逾期」；每天提醒会在次日同时间再次触发。

**Q：手机收不到提醒/文档？**
1. 手机与电脑同一 WiFi，地址与令牌正确；
2. 手机端允许通知；后台任务（WorkManager）可能在省电模式下延迟；
3. 文档需在 App「文档」页刷新后下载。

**Q：连不上 Home Assistant / MQTT？**
1. 地址/端口/令牌（或账号密码）是否正确；HA 需长期访问令牌；
2. 电脑与设备是否同一局域网、防火墙是否放行；
3. 点设置页「测试连接」看返回错误。

**Q：SSDP 发现不到设备？**
1. 设备需支持 UPnP/SSDP 且与电脑同一局域网；
2. 部分设备广播被路由器/防火墙拦截；
3. SSDP 发现仅能查看，控制需经 HA/MQTT。

**Q：令牌在哪？**
桌面程序「设置/中枢连接」可看；或仓库 `data/secrets.json` 的 `operatorToken`；手机 App 设置页填写同一个。

**Q：没真机能用吗？**
能——桌面端完整可用；手机 App 为体验包，通知/分享/屏幕采集需在真机确认。

## 14. 已知边界（不吹）

- **手机未真机实测**：APK 0.6 只完成构建 + lint + 静态校验；安装、通知、文档分享、屏幕授权需真机确认。
- **无真实家居设备**：HA/MQTT/SSDP 用本地桩验证协议链路；真实品牌设备需按要求接入 HA/MQTT 后用你自己环境验证。
- **不直连厂商云**：小米/华为/苹果/Aqara/涂鸦等经 HA 或 MQTT 网关桥接；本轮不做厂商账号授权。
- **SSDP 设备可能不可控**：发现仅能查看，控制取决于设备 UPnP 实现。
- **提词器、手机通知转发**：本轮未实现，属下一轮（见雷鸟对照文档）。
- **天气**：今日看板暂无天气数据源。
- 局域网内使用明文 HTTP（仅限可信内网）；正式分发前应移除体验用默认令牌。
