| 项 | 值 |
|---|---|
| 适用版本 | v2-P0（开发中） |

## 1. 开始之前

1. **电脑端**：按 v0.1.0 的方式启动中枢与节点（`node server/start.js` + `node node-agent/agent.js`，或 `scripts/启动.cmd`）。v2 的新能力在同一中枢上演进，端口仍是 7410。
2. **手机端**：安装 Android 原生 App（P0 交付 APK；要求 Android 8.0 / API 26 及以上），与电脑连**同一 WiFi**。
3. **登录与令牌**：控制台只读可看；写操作（配对、传输、入库、执行场景、企业设置）仍需操作令牌（启动日志或 `data/secrets.json` 的 `operatorToken`）。
4. **数据位置**：`data/link/`（信任设备与传输临时文件）、`data/assets/`（索引与缩略图）、`data/basket/`（中转站）、`data/enterprise/`（成员与策略）。全部默认留在本机。
5. **页面入口**：桌面控制台左侧导航新增「互联 / 素材库 / 中转站 / 场景 / 企业控制台」，对应路由见 §2；原有 9 页（总览/设备/能力/任务/消息/体检/审计/演练/设置）保持不变。

## 3. 互联（`#/link`）

### 3.1 发现设备

1. 确认电脑节点进程在线、手机 App 已打开且与电脑同一 WiFi。
2. 打开 `#/link`，设备列表会自动出现（局域网 UDP 广播，默认端口 7413）。
3. 没出现时：点「重新发现」；或手输电脑 IP 兜底。
4. 设备卡片显示：名称、平台（Windows/Android）、在线状态、IP。

### 3.2 配对

1. 电脑端进入 `#/link` →「配对」，显示 **6 位配对码**和二维码。
2. 手机端扫码（二维码内容为 `tenon://pair?...`），或手输 IP + 6 位配对码。
3. 配对成功后设备进入「信任设备」列表；之后可免码传输。
4. 撤销：信任设备列表 →「撤销」→ 该设备立即失去传输/剪贴板权限（已接收文件与账本记录保留）。
5. 配对失败排查：是否同一 WiFi、电脑防火墙是否放行 7410/7413、二维码是否被旧码覆盖。

### 3.3 传文件（手机 ↔ 电脑）

1. 选目标设备 → 选文件（支持批量、任意大小）。
2. 传输中显示进度、速度、剩余时间。
3. 中断（断网/切后台）后再次传输会从已传位置继续（**断点续传**）。
4. 完成后自动做 **SHA-256 校验**：显示「校验通过」或「校验失败（可重传）」。
5. 电脑端接收目录由节点配置（P0 默认接收目录以交付说明为准）。

### 3.4 剪贴板 / 链接

1. 手机 App 打开「剪贴板同步」（Android 前台服务，需用户授权）。
2. 手机复制文字或链接 → 电脑端「剪贴板」区出现最新内容 → 一键写入电脑剪贴板。
3. 电脑端复制内容 → 手机通知可见 → 点通知写入手机剪贴板（Android 前台场景）。
4. 关闭开关即停止同步；剪贴板内容只在本机/局域网流转。

### 3.5 通知镜像

- 手机通知在电脑端「通知」列表可见（应用名、标题、摘要、时间）。
- 可在手机端关闭通知监听授权，关闭后不再镜像。

### 3.6 信任设备管理

- 查看已配对设备与最近活动时间；可撤销、可重新配对。
- 撤销与配对均写入事件账本（`link.paired` / `link.revoked`），审计可查。

## 4. 素材库（`#/assets`）

### 4.1 导入

- **电脑**：指定文件夹扫描入库；或上传文件。
- **手机**：App 内上传；或从相册/文件管理器「分享到榫卯」（分享目标，P0）。
- **去重**：按内容 SHA-256 去重，相同内容只保留一条记录，重复导入会提示「已存在」。
- 入库后异步生成缩略图与 OCR 文本；处理中的素材显示「处理中」。

### 4.2 搜索与筛选

- 搜索框支持：文件名、OCR 文本、标签。
- 筛选：类型（图片/文档/视频等）、来源设备、时间范围。
- 结果可切换网格/列表视图。

### 4.3 素材详情

- 大图/预览、文件名、大小、类型、来源设备、原始路径、SHA-256、入库时间、标签。
- **引用**：被哪些任务/场景使用；**谱系**：ingest / tag / share / remove 事件可从账本追溯。
- 可加入中转站、写入场景步骤、导出。

### 4.4 标签

- 手动打标签、按标签筛选；AI 自动标签见 §4.6。

### 4.5 与中转站联动

- 素材库批量选择 →「加入中转站」→ 在 `#/basket` 按目标设备取用（见 §5）。

### 4.6 P1/未实现（本版本不提供）

- 语音搜索 / 语音转写标签 → **P1/未实现**
- 视觉标签（识别画面内容自动打标）→ **P1/未实现**
- 语义搜索（自然语言找素材）→ **P1/未实现**
- 素材版本管理与版本对比 → **P1/未实现**

## 5. 中转站（`#/basket`）

1. 手机 App 把文件/图片「暂存到中转站」（也支持桌面端素材库批量加入）。
2. 电脑端打开 `#/basket`：看到暂存列表（文件名、大小、来源设备、时间）。
3. 选目标设备 →「一次取用」：下载到本机 / 收进素材库 / 加入场景步骤。
4. 取用后可手动清除；同一项可多次取用。
5. 暂存容量与过期策略以 P0 交付说明为准（不在本手册假设）。

## 6. 场景（`#/scenes`）

### 6.1 内置 3 个场景（P0）

| 场景 | 做什么 | 风险 | 是否需要确认 |
|---|---|---|---|
| 打印素材 | 把选中的一张素材交给打印服务器打印 | 不可逆（出纸） | **必须逐次确认** |
| 投屏照片到电脑 | 让电脑屏幕打开/显示一张照片 | 可逆 | 不需要 |
| 备份到 NAS / 文件夹 | 把素材复制到目标目录或 NAS | 覆盖已有文件视为不可逆 | 覆盖时**必须确认** |

### 6.2 新建场景

1. `#/scenes` →「新建场景」，填写名称。
2. 添加步骤：选择动作（来自物模型）、目标设备、参数。
3. 标记哪些步骤需要确认；保存（写 `scene.defined` 事件）。

### 6.3 执行场景

1. 选择场景 →「运行」。
2. 不可逆步骤弹确认框：写清**将发生什么、影响谁、能否撤销**；不确认不执行。
3. 执行过程显示每一步结果；失败时显示卡在哪一步。
4. 执行记录写账本（`scene.ran`），可在审计页导出。

### 6.4 物模型说明

- 每台设备的能力被统一映射为「属性 / 动作 / 事件」；动作带风险等级（可逆/不可逆）与参数说明。
- 「仅手动」能力不会被场景自动执行。

## 7. 企业控制台（`#/enterprise`）

### 7.1 成员与角色

- 角色：**管理员 / 成员 / 访客**；管理员可邀请成员（邀请码）、改角色。
- 成员越权请求会被拒绝并留痕（`enterprise.denied`）。

### 7.2 动作权限

- 按角色勾选允许的动作白名单；未勾选的动作对该角色不可用。

### 7.3 审批

- 打开「不可逆动作需审批」开关后，成员执行不可逆动作会先生成审批请求（`approval.requested`），管理员通过/拒绝（`approval.decided`）后才执行。

### 7.4 审计与保留期

- 审计导出：CSV / JSON / Markdown。
- 审计保留期：7 / 30 / 180 天可配（P0 提供配置项；实际清理策略以交付说明为准）。

### 7.5 身份集成（企业提供凭据）

- 企业微信 / 钉钉 / SSO：P0 提供**适配器接口 + mock**；真实对接需要企业提供测试租户或凭据 → **P1/未实现（真实对接）**。

### 7.6 私有化部署

- 沿用 v0.1.0 的数据目录与部署脚本；数据、日志、调用记录都在自己的服务器上，默认零外联。

## 8. 家庭形态（P0 基础）

- 家庭成员邀请、家庭相册共享、访客只读/限时。
- 家庭形态不启用企业审批流与 SSO；共享范围限定在家庭空间内。

## 9. 权限、隐私与安全

- **Android 权限**：剪贴板前台服务、通知监听（`NotificationListenerService`）、文件/相册访问、局域网访问（首次使用会请求，可拒绝）。
- 数据默认只在本机与局域网流转；剪贴板/通知开关可随时关闭，关闭即停止采集。
- 撤销配对后设备不能继续传输；所有配对、传输、素材、场景、审批动作写入事件账本，可导出审计。
- 删除素材会写 `asset.removed` 事件，不做静默删除；操作令牌与节点令牌策略沿用 v0.1.0。

## 11. 常见问题（目标行为；P0 验收后以实测为准）

- **手机搜不到电脑？** 确认同一 WiFi、电脑节点进程在线、防火墙放行 7410/7413；仍不行用手输 IP。
- **传输中断了怎么办？** 重新发起传输，会从断点继续；完成后看 SHA-256 校验结果。
- **同一张图导入两次？** 内容哈希相同会去重，只保留一条记录。
- **OCR 搜不到？** OCR 是异步队列，稍等后刷新；图片模糊/无文字时识别结果为空属正常。
- **剪贴板不同步？** 检查手机端剪贴板同步开关与前台服务权限；Android 各厂商对后台限制不同。
- **场景执行失败？** 看步骤与目标设备是否在线、动作是否有权限、不可逆动作是否已确认/审批。
- **成员操作被拒？** 管理员检查该角色动作白名单与审批开关；拒绝会留痕。
