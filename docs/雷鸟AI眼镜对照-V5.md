# 雷鸟 AI 眼镜官方功能 × 榫卯 V5 对照

> 调研时间：2026-10-31（信息来自雷鸟 AI 眼镜 App Store 官方页面、RayNeo 官网与公开报道）。本文件只做**能力对照**：雷鸟是「AI 眼镜 + 手机 App」，榫卯是「桌面超级终端 + 手机 App + 网页」，两者形态不同，但用户要的「看板 / 记录 / 总结 / 提醒 / 对话 / 物联」可以逐项映射。
>
> 状态口径：✅ 已实现；🟡 已有基础；⏳ 下轮（未实现）。不把未做的写成已做。

## 一、官方 App 公布的 7 项核心功能

1. **看板**：轻量看板展示日程、待办、天气等。
2. **实时字幕**：眼镜上提供翻译与字幕辅助。
3. **AI 录音总结**：记录音频 → 生成摘要、重点、待办、回顾。
4. **提词器**：眼镜上提词，减少低头看手机/稿件。
5. **手机通知提醒**：把手机通知显示在眼镜上。
6. **全天智记**：用户授权后记录日常沟通，生成 AI 日记。
7. **与 RayNeo AI 对话**：提问、建议、信息回顾。

## 三、形态差异（不是同类产品，但互补）

| 维度 | 雷鸟 AI 眼镜 | 榫卯 V5 |
|---|---|---|
| 硬件 | AI 眼镜 + 手机 App | Windows 桌面程序 + Android App + 网页 |
| 主入口 | 眼镜显示 + 语音 | 桌面大屏 + 语音唤醒 + 手机 |
| 数据 | 厂商 App/云 | **本地优先**：音频、屏幕文字、笔记只存本机；仅唤醒命令与总结文本发 DeepSeek |
| 记录 | 录音摘要 + AI 日记 | 语音笔记（可编辑/搜索/导出）+ 结构化总结 + 文档中心 |
| 控制 | 眼镜交互 | 真实执行程序/命令/设备（不可逆需确认 + 审计） |
| 物联 | 未公开强调 | HA/MQTT/SSDP 标准协议接入，可桥接大品牌 |

## 四、结论

- 用户要的「看板 / 记下来 / 真正的总结 / 发到手机 / 提醒 / 大品牌物联」在 V5 都有对应实现；**提词器**与**手机通知转发**两项明确属于下轮，本轮不写进已做清单。
- 与雷鸟的差异是形态：雷鸟把信息放到眼镜上；榫卯把信息落成本地笔记与文档、并在桌面/手机上执行与提醒。
