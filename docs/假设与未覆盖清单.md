# 假设与未覆盖清单

> 诚实边界。已覆盖的写「已验证（证据）」，没做过的写「未覆盖」，不把没测的写成已测。

## 技术假设

1. 单机形态下，中枢与节点跑在同一台 Windows 电脑上，用不同进程模拟「中枢 ↔ 节点」边界；同一份节点代码可在 Linux/macOS 上运行（**未实机验证**，启动脚本提供）。
2. 手机端以**手机浏览器 + PWA 方式**接入局域网中枢；不做原生 Android APK（**未覆盖**）。
3. AI 层默认使用 DeepSeek 兼容接口；离线时降级为规则引擎草案 + 显式「未知」，不伪造结果。
4. 图片能力（PNG 裁方图）纯 JS 实现，不依赖外部二进制；JPEG 解码不在 v0.1.0 范围（示例素材统一转 PNG）。
5. 事件账本单写者模型：同一数据目录只允许一个中枢实例写，第二个实例只读。
6. 数据目录默认位于项目内 `data/`，随项目文件夹迁移。

## 未覆盖 / 未验证

| 项 | 状态 | 说明 |
|---|---|---|
| 物理拔网线演练 | 未覆盖 | 用「断网演练」开关真实切断外联验证功能不减；不实际断开你正在使用的网络 |
| 手机真机接入 | 未验证 | 用真实 Chrome 的手机视图（420px 容器）模拟；真机需同一局域网按文档接入 |
| 真实微信/QQ 通道 | 接口就绪，模拟通道验证 | 需 webhook/企业微信凭据才能切真；界面明确标「模拟通道」 |
| 真实邮件通道 | 接口就绪 | 需 SMTP 凭据；v0.1.0 用接口 + 本地模拟 |
| 真实打印机 | 未覆盖 | 提供 `printer.mock` 能力与真实接口位置 |
| macOS / Android 原生节点 | 未覆盖 | 节点脚本同构，未实机验证 |
| 企业形态（机房高可用） | 配置层就绪 | 不做真机房验证 |
| GUI 点击兜底 | 未覆盖 | 列为路线图；v0.1.0 只在显式授权设计层面预留 |
| 跨数据域审批的真实多人流程 | 单机单人验证 | 角色与数据域标记已实现，多人协作未实测 |

## 明确不做的降级

- 任何不可判定的一律显示「未知」并说明缺哪条证据，不用「通常/应该」填空。
- 体检没有发现时输出「未发现问题」并列出检查范围，不假装通过。
- 数据过期（>24h）显示数据时间并提示重跑。
