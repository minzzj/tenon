## 4. 故障与边界演练

- **强杀重启**：真实 `job_kill` 杀中枢与节点 → 重启。账本重放恢复 < 1 s；比对 `task.started` / `task.succeeded` 计数确认无重复执行；缺口显式写 `system.crashRecovery`；某次演练后账本 **520 条事件**，seq 连续、`prev` 哈希链完整。
- **双实例**：同一数据目录启动第二个中枢 → 自动只读，写操作 423（A9）。
- **断网演练**：`#/drills` 的断网开关真实切断外联 → 页面可用、审计连续、AI 降级、通道改站内（A7）；恢复后自动恢复。
- **断开设备**：先出影响预览，确认后 275 ms 内 3 条引用任务降级（A5/A6）。
- **通道限流**：种子任务 `seed_task_03` 展示完整降级链「微信限流 → 排队重试 → 改邮件 → 延迟约 10 分钟送达」；通道状态机另由 `channels.test.js` 的 10 条单测覆盖。

## 7. 十分钟手工验收路线

按用户路径走一遍，即可复核上面的结论：

1. 双击 `scripts/启动.cmd` → 自动开中枢窗口、节点窗口与浏览器 `http://127.0.0.1:7410`。
2. 手机页 `http://<电脑IP>:7410/m`（局域网访问需以 `TENON_HOST=0.0.0.0` 启动中枢）输入「把昨天的样品图裁成方图」→ 桌面任务页出现五段草案。
3. 找一条不可逆任务（如「发送交付链接到工作群」）→ 未确认不执行；点拒绝 → 时间线原因「未填写」，审计留痕。
4. 设备页选「打印服务器」→ 断开前先看影响预览（确定 3 / 可能 1 / 未知 1）→ 点取消，状态零变化 → 再确认断开，三处 275 ms 内变「待确认」。
5. 体检页跑一次全量体检 → 看到「发现 9 项」；再跑 channels 范围 → 「未发现问题，已检查 1 项」；导出 Markdown。
6. 审计页导出 CSV / JSON，检查 seq 连续、事件与操作一一对应。
7. 演练页打开断网演练 → 页面可用、AI 显示规则降级；恢复。
8. 直接关闭/强杀中枢窗口 → 重新启动 → 任务未重复、事件未丢、缺口有「缺失约 N 分钟事件」标记。
