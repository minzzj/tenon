# 使用手册（v0.1.0）

> 本手册随 v0.1.0 实现同步补齐截图与数字。当前版本描述**将要如何用**，命令在代码落地后生效。

## 1. 十分钟跑起来

```bash
# 1) 拿到代码
git clone https://github.com/minzzj/tenon.git
cd tenon

# 2) 启动中枢 + 本机节点（首次运行自动生成操作令牌）
node server/start.js          # 默认 http://127.0.0.1:7410

# 3) 打开桌面控制台
#    浏览器访问 http://127.0.0.1:7410

# 4) 手机端（同一局域网）
#    手机浏览器打开 http://<电脑IP>:7410/m
```

## 2. 界面导览

| 页面 | 回答的问题 | 关键操作 |
|---|---|---|
| 设备卡（L0） | 它是谁、能做什么、谁在用 | 看能力、点证据、补扫、隐身 |
| 能力视图 | 这条能力被谁引用 | 点开最近三次调用与授权到期 |
| 任务看板 | 这件事办到哪一步 | 确认/拒绝、取消、重试、看时间线 |
| 影响预览 | 断开后会断哪些任务 | 确定/可能/未知三级；取消零变化 |
| 消息收件箱 | 结果怎么回来的 | 摘要+链接、限流/换通道/未送达 |
| 上线体检 | 现在哪里有问题 | 阻断/警告/提示/无法判定；导出报告 |
| 审计 | 谁在何时动了什么 | 导出 CSV / JSON / Markdown |

## 3. 手机端「说一句」

1. 手机页输入一句话（例：`把昨天的样品图裁成方图`）。
2. 中枢生成**五段草案**：任务草案 / 用到的能力 / 目标设备 / 缺失项 / 风险等级。
3. 可逆动作可直接派发；**不可逆动作必须逐次确认**，确认文案写清「将发生什么、影响谁、能否撤销」。
4. 完成后回执只含摘要与链接；正文需登录查看。

## 4. 启动器与停止

- Windows：双击 `启动.cmd`（v0.1.0 提供）→ 自动打开浏览器。
- 停止：`停止.cmd` 或关闭窗口；数据在 `data/`，重启自动重放账本恢复。

## 5. 配置

| 配置项 | 作用 | 默认 |
|---|---|---|
| `TENON_MODE` | `solo` / `team` / `enterprise` | `solo` |
| `TENON_HOST` | 监听地址 | `127.0.0.1`（团队模式 `0.0.0.0`） |
| `DEEPSEEK_API_KEY` | AI 草案/解释/诊断 | 未设置时规则引擎降级 |
| `TENON_DATA_DIR` | 数据目录 | `./data` |

## 6. FAQ（v0.1.0 补实测答案）

- 断网还能用吗？—— 能：本机/LAN 功能不减，AI 与外部通道显式降级。
- 数据存在哪？—— 项目内 `data/events.jsonl`（追加式账本）+ 索引；可导出。
- 怎么迁移？—— 复制数据目录，启动自动重放；任务会标「待确认」。
- 卸载干净吗？—— 删除目录即可；不留后台进程与残留权限。
