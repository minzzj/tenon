# 使用手册（v0.1.0 · 2026-10-25 交付）

> 适用版本 **v0.1.0（2026-10-25 交付）**。本手册里的命令、路径、界面均在本轮实测中真实运行过；没做的部分写进 [假设与未覆盖清单](假设与未覆盖清单.md)，不在这里假装可用。

## 1. 环境要求

| 项 | 要求 | 实测环境 |
|---|---|---|
| Node.js | **>= 22**（零运行时依赖，不需要 `npm install`） | v24.15.0 |
| 操作系统 | Windows 10/11 可用一键启动器；macOS / Linux 可手动跑同一套 Node 命令 | Windows 10（19041） |
| 浏览器 | 现代 Chrome / Edge（无 CDN、无外链字体，断网可用） | 真实 Chrome 1280×800 |
| 手机 | 与电脑同一局域网；手机浏览器打开 `/m` 页面 | 用桌面 Chrome 的手机布局验证（未用真机，见边界） |
| 可选 | Python 3 + Pillow（仅重新生成示例图片时用到） | Python 3.11 |

## 2. 启动产品

### 2.1 Windows 一键（推荐）

1. 进入仓库根目录。
2. 双击 `scripts/启动.cmd`。
3. 它会依次打开：**中枢窗口**（`node server\start.js`）、**节点窗口**（`node node-agent\agent.js`）、**浏览器** `http://127.0.0.1:7410`。
4. 首次启动会在 `data/` 自动生成 `secrets.json`（操作令牌 + 节点令牌），并在中枢窗口打印**操作令牌**。
5. 停止：运行 `scripts/停止.cmd`（结束 7410 端口进程与节点进程），或直接关闭两个窗口（Ctrl+C）。

### 2.2 手动启动（任意系统）

```bash
cd <仓库根>
node server/start.js          # 终端 1：中枢，默认 http://127.0.0.1:7410
node node-agent/agent.js      # 终端 2：节点，默认连 http://127.0.0.1:7410
```

中枢启动日志会打印：版本、模式、数据目录、桌面控制台地址、手机端局域网地址、操作令牌、节点令牌文件位置。首次启动自动生成 `data/secrets.json`，之后复用同一份令牌。注意默认只监听 `127.0.0.1`，局域网手机访问需以 `TENON_HOST=0.0.0.0` 启动（见 §7）。

### 2.3 停止

- Windows：`scripts/停止.cmd`，或关闭窗口 / Ctrl+C。
- 手动：两个终端分别 Ctrl+C。
- 数据保留在 `data/`，下次启动自动重放账本；非正常关闭会在下次启动时标记事件缺口（不会重复执行任务）。

## 3. 登录与令牌

**只读浏览不需要登录**：总览、设备、能力、任务、消息、体检、审计、演练、设置页首屏都可直接看。

**写操作需要操作令牌**：生成草案、确认/拒绝/取消/重试、断开设备、跑体检、导出、触发演练。

- 桌面端：点右上角「登录 / 令牌」按钮（或设置页「操作令牌」卡片）输入；成功后右上角显示「已登录·可写」。
- 手机端：首次写操作时页面要求输入令牌，提示「写操作需要令牌：输入启动日志里的 operatorToken」；令牌保存在本机 localStorage。
- 令牌来源：**启动日志**里的 `操作令牌: tok_...`，或 `data/secrets.json` 里的 `operatorToken`。
- 回执链接 `/r/<taskId>`：消息里只带摘要与链接；未登录打开只显示「需要登录查看正文」，输入令牌后才显示完整时间线。
- 清除令牌：设置页「清除令牌」，回到只读浏览。
- **节点令牌**（`nodeToken`）：节点进程自动从 `data/secrets.json` 读取，无需人工输入。

## 4. 界面导览

| 页面 | 回答的问题 | 关键操作 |
|---|---|---|
| 总览 | 三个问题的入口 + 设备卡摘要 | 看在线数、能力数、待确认数、回执数 |
| 设备 | 这台机器能做什么、谁在用、证据是什么 | 看能力、点证据、断开（**先出影响预览**）、补扫、隐身 |
| 能力 | 这条能力被谁引用、最近三次调用、授权何时到期 | 点开关系与证据；无证据显示「未知」 |
| 任务 | 这件事办到哪一步 | 一句话生成五段草案、确认/拒绝/取消/重试、看时间线 |
| 消息 | 结果怎么回来的 | 摘要 + 链接、限流/换通道/未送达状态 |
| 体检 | 现在哪里有问题 | 阻断/警告/提示/无法判定；空结果列出检查范围；导出 Markdown |
| 审计 | 谁在何时动了什么 | 导出 CSV / JSON / Markdown |
| 演练 | 故障时能不能顶住 | 断网、限流、授权过期、版本不兼容、循环阻止、磁盘满、跨域、无记录设备、角色不足等演练开关，一键恢复 |
| 设置 | 运行环境与令牌 | 模式/数据域/数据目录/版本、AI 状态与 token 用量、操作令牌、许可证 |

## 5. 手机端「说一句」

1. 启动中枢后，手机与电脑连同一局域网，用手机浏览器打开 `http://<电脑IP>:7410/m`（启动日志会打印局域网地址；Windows 防火墙需放行端口）。
   - **注意**：中枢默认只监听 `127.0.0.1`，局域网手机访问需要以 `TENON_HOST=0.0.0.0` 启动中枢（见 §7）。
2. 输入一句话（示例：`把昨天的样品图裁成方图`）→ 点「交给电脑」。
3. 桌面端任务页出现五段草案：**任务草案 / 用到的能力 / 目标设备 / 缺失项 / 风险等级**。
4. 可逆动作免确认直接派发；**不可逆动作停在「待确认」，必须逐次确认**（文案写清将发生什么、影响谁、能否撤销）。拒绝也会留事件，原因默认「未填写」。
5. 完成后回执只含**摘要 + 链接**；正文在桌面端登录后查看。
6. 中枢不可达/断网时：手机页显示本机缓存（设备卡、任务历史）与横幅「离线 · 数据截至 HH:mm（缓存）」，此时只读；恢复后自动刷新。
7. 手机端的写操作需要操作令牌（首次输入后保存在浏览器 localStorage）。

## 6. 演示数据与重置

```bash
# 重置演示数据：清空 data/ 事件账本，写入可重放的种子数据
node scripts/seed-demo.js --fresh

# 重新生成示例图片（需要 Pillow：pip install pillow）
python scripts/gen-samples.py
```

`seed-demo.js --fresh` 写入的真实内容（2026-10-25 实测）：

- **71 条事件 / 11 条任务 / 2 份体检 / 2 条消息 / 2 条审计导出**；seq 连续、哈希链完整。
- 11 条任务覆盖已完成、失败、待确认、草案、已取消等状态；其中 **3 条待确认任务引用「打印服务器」**，专门用于演示断开影响（预览结果：确定 3 / 可能 1 / 未知 1）。
- 2 份体检：「发现 9 项」与「未发现问题，已检查 1 项」各一份（真实 `runCheckup()` 产物）。
- 消息 2 条，分别走微信（模拟通道）与邮件（模拟通道），含一条「限流→改邮件」的降级记录。

> ⚠ `--fresh` 会清空当前 `data/` 事件账本，只用于演示/评审环境；正式数据请先备份。

示例图片：`python scripts/gen-samples.py` 生成 `示例空间/样品图/样品01–09.png`（不同尺寸）与 0 字节坏样本 `样品10.png`，以及 `示例空间/临时/过期草稿.png`。图片能力输出在 `示例空间/输出/方图/`（1024×1024 PNG）；模拟打印输出在 `data/outbox/打印-<时间>.txt`。

## 7. 配置（环境变量）

| 变量 | 作用 | 默认值 |
|---|---|---|
| `TENON_MODE` | 运行形态标记：`solo` / `team` / `enterprise`（写入启动事件与状态快照，体检按形态提示；团队/企业的审计保留策略属配置层，见假设清单） | `solo` |
| `TENON_HOST` | 监听地址；**手机局域网访问需设为 `0.0.0.0`** | `127.0.0.1` |
| `TENON_PORT` | 端口 | `7410` |
| `TENON_DATA_DIR` | 数据目录（相对仓库根或绝对路径） | `./data` |
| `DEEPSEEK_API_KEY` | 可选：真实 DeepSeek 接入（草案/解释/摘要），不设置则规则引擎降级 | 未设置 |

高级可选项（真实存在）：`DEEPSEEK_BASE_URL`（默认 `https://api.deepseek.com`）、`DEEPSEEK_MODEL`（默认 `deepseek-chat`）；节点侧 `TENON_HUB_URL`、`TENON_NODE_NAME`、`TENON_NODE_ID`、`TENON_NODE_TOKEN`。

设置方式（Windows CMD 示例）：

```bat
set TENON_HOST=0.0.0.0
set TENON_MODE=team
node server\start.js
```

Linux 部署脚本 `scripts/install.sh` 会把配置写进 `.env` 样例；Node 不会自动读 `.env`，启动前需要导入，例如：

```bash
set -a && . ./.env && set +a && node server/start.js
```

**只读实例**：同一数据目录第二次启动会自动只读（写操作返回 423「另一窗口为只读」），也可显式 `node server/start.js --read-only`。

## 8. 数据、备份与迁移

`data/` 目录（可通过 `TENON_DATA_DIR` 改）：

| 文件 | 内容 |
|---|---|
| `events.jsonl` | **追加式事件账本（唯一事实来源）**，带 seq 与哈希链 |
| `secrets.json` | 操作令牌 `operatorToken` 与节点令牌 `nodeToken`（勿外传、勿提交仓库） |
| `node-identity.json` | 节点身份（删掉会被中枢当成新节点） |
| `node-state.json` | 节点已完成任务记录（幂等，防重复执行） |
| `hub.lock` | 单写者锁（第二实例据此转只读） |
| `seed-summary.json` | 种子数据摘要（执行 `seed-demo.js` 后生成） |
| `outbox/` | 模拟打印的输出打印单 |

- **备份**：停机后复制整个 `data/`（至少 `events.jsonl` + `secrets.json`）。
- **迁移**：把 `data/` 复制到新机器同一版本产品下 → 启动自动重放账本；在途任务会标「待确认」，不会重复执行。
- **崩溃恢复**：强杀后重启，账本重放 < 1 s，事件缺口显式标记（`system.crashRecovery`，文案「缺失约 N 分钟事件，任务未重复」）。
- **审计导出**：审计页导出 CSV / JSON / Markdown；体检报告导出 Markdown。

## 9. 常见问题（实测口径）

- **断网还能用吗？** 能。本机/局域网功能不减；手机页显示缓存与「数据截至 HH:mm」；AI 自动降级为规则引擎，外部通道显式降级/停用，不静默失败。
- **需要 `npm install` 吗？** 不需要。零运行时依赖，只用 Node.js 内置模块。
- **手机打不开 `/m`？** 三个检查：① 手机和电脑同一局域网；② 中枢以 `TENON_HOST=0.0.0.0` 启动（默认只监听 127.0.0.1）；③ Windows 防火墙放行端口。启动日志会打印可用的局域网地址。
- **端口 7410 被占用？** 先跑 `scripts/停止.cmd`，或 `set TENON_PORT=7411` 后启动（桌面端与手机端地址同步改端口）。
- **操作令牌丢了？** 重启中枢会再次打印；也可直接看 `data/secrets.json` 的 `operatorToken`。
- **会重复执行任务吗？** 不会。任务哈希/幂等键 + 节点完成记录双重保证；4 次强杀重启实测无重复 `task.succeeded`/`task.started`。
- **开了两个中枢会怎样？** 第二个自动只读，写操作返回 423，不会写坏账本。
- **AI 为什么显示「规则引擎」？** 未配置 `DEEPSEEK_API_KEY`、预算耗尽（单轮 20 次调用 / 4 万 tokens）或断网时，自动降级为规则引擎并显式标注，不伪造结果。
- **卸载干净吗？** 关闭中枢/节点窗口（或 `停止.cmd`）后删除整个目录即可；没有系统服务、没有开机自启、不写注册表。

## 10. 边界与未覆盖

微信/邮件为**适配器接口 + 模拟通道**（真实通道需 webhook / SMTP 凭据）；手机为**桌面 Chrome 的 `/m` 页面 + 独立浏览器截图**（未用真机）；**物理拔网线未做**（用断网演练开关）；`printer.mock` 不连真实打印机；macOS/Android 原生节点未实机验证；企业形态为配置层就绪。完整清单见 [假设与未覆盖清单](假设与未覆盖清单.md)。
