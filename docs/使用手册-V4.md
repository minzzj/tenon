# 使用手册 · 榫卯超级终端 V4（v0.5.0）

> 适用版本 **v0.5.0（2026-10-30）**：一个 Electron 桌面程序「榫卯超级终端」，托盘常驻，说话即可调动电脑程序与家里设备；屏幕文字本地识别，每天 23:00 自动写总结；手机 APK 0.5 录音送电脑识别。
>
> 本手册里的路径、菜单与操作均以仓库内实际实现为准；没做的部分写在 §10「已知边界」，不写成可用。

## 1. 这是什么

| 项 | 说明 |
|---|---|
| 形态 | **一个桌面程序**（Electron），不是网页 + 一堆脚本；有单文件便携版，托盘常驻，关闭窗口不退出 |
| 能做什么 | 说一句话（唤醒词「榫卯」）→ 执行器规划并执行：打开程序/网页、调音量、放音乐/视频、打印、流转内容到电脑大屏、运行命令、控制设备 |
| 屏幕理解 | 电脑本地用 Windows 系统字库 OCR 记录屏幕文字（非大模型、不联网）；自测 3/3 ≥90%，5 张真实截图平均准确率 98.2%，单张约 250–800ms；视频标题/字幕/聊天内容也能进「今日」 |
| 每日总结 | 每天 23:00 汇总当天语音 + 屏幕文字 + 任务 → DeepSeek → 「今天做了什么 / 明天要做什么 / 日记」；live 实测 1383 字、三部分齐全 |
| 手机 | APK 0.5：录音送电脑识别执行、屏幕采集上报、设备一键绑定/一键动作（未真机实测） |
| 隐私 | 音频与屏幕文字只存本机 `data/`；仅唤醒后的命令文本与每日总结会发 DeepSeek |

## 2. 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（64 位），可用麦克风 |
| Node.js | **>= 22**：单文件便携版**不需要**另装（内置运行时）；用 `启动超级终端.cmd` 或开发模式时需要 |
| Python 3 | 本地语音识别（FunASR worker）与屏幕 OCR 依赖本机 Python 环境（`scripts/voice/`、`scripts/screen/`，需 Pillow、winrt 等；见仓库脚本说明） |
| Python 3 | 屏幕 OCR/采集用（需要 `Pillow`；Windows 系统 OCR 需要 `winrt` 运行库；字体相似度校验另需 `numpy`） |
| 浏览器 | 不需要额外装——界面在桌面程序内打开 |
| 手机 | Android 8.0+（minSdk 26），与电脑同一 WiFi |
| 网络 | 局域网内即可工作；每日总结与 AI 规划可选接 DeepSeek（需要 API key） |

## 3. 启动与退出

### 3.1 三种启动方式

1. **双击单文件便携版** `desktop/release/TenonSuperTerminal-0.5.0-portable.exe`（约 120 MB，双击即启动，内置运行时）；
2. **双击桌面「榫卯超级终端」快捷方式**（`榫卯超级终端.lnk`）；
3. 仓库根目录双击 **`启动超级终端.cmd`**（仓库内运行，需要本机 Node.js >= 22）；
4. 开发模式：`cd desktop && npm start`。

旧版完整控制台保留在 `http://127.0.0.1:7410/legacy`（托盘「打开完整控制台（旧版）」也可进入）。

首次启动会自动：生成本地数据目录（首次启动自动生成 `data/secrets.json`，内含操作令牌）→ 启动本地中枢 `http://127.0.0.1:7410` → 启动屏幕采集（若环境满足）→ 打开「超级终端」窗口。

### 3.2 托盘菜单（右键托盘图标）

| 菜单项 | 作用 |
|---|---|
| 打开超级终端 | 显示/唤醒主窗口 |
| 打开完整控制台（旧版） | 打开旧版控制台（互联/素材/审计等高级页面） |
| 暂停语音监听 / 开启语音监听 | 临时关掉/打开麦克风监听（不退出程序） |
| 暂停屏幕采集 / 开启屏幕采集 | 临时停止/恢复屏幕文字采集（对应 `data/voice/screen.pause` 暂停标记） |
| 现在生成今日总结 | 立即生成今天的总结与日记（不必等 23:00） |
| 开机自启 | 勾选后随 Windows 登录启动 |
| 打开数据目录 | 打开 `data/` 查看本地数据 |
| 退出榫卯 | 真正退出（同时停止语音与采集） |

### 3.3 退出与卸载

- **关闭窗口 = 收到托盘**，程序仍在后台监听/采集；要完全退出请在托盘菜单点「退出榫卯」。
- 卸载：先托盘退出 → 删除整个程序目录（或卸载包）；数据在 `data/`，删除即清空（建议先备份）。

## 4. 首页：「超级终端」

打开程序默认进入「首页」，从上到下：

1. **顶栏**：品牌「榫卯 · 超级终端」+ 在线圆点；右侧两个状态徽标（语音：待机/正在聆听；屏幕：采集中/已暂停）和 **⚙ 设置**按钮。
2. **大麦克风（🎙）**：点一下开始/结束一次录音；开常驻监听时也可直接用唤醒词。
3. **单行实时字幕**：识别中的内容灰色显示，最终结果高亮——**同一句只显示一条**（v0.5 修复了两行重复问题）。
4. **命令输入框（兜底）**：也可以直接打字，例如「打开记事本，把音量调到 60」，点「发送」。
5. **结果卡**：AI 回复（人话）+ 执行步骤（✅ 成功 / ⏳ 进行中 / ❌ 失败 / ⚠ 待确认）+ provider 与耗时；需要确认的动作会出现「确认执行 / 取消」。
6. **快捷命令**：打开记事本 / 音量 60 / 回家模式 / 总结今天，点一下即执行。
7. 底部 **4 个页签**：首页 / 设备 / 今日 / 设置。

## 5. 说话就能办事

1. 说「**榫卯**」唤醒（或点麦克风开始一次录音），然后说出要求，例如：
   - 「打开记事本」
   - 「把音量调到 60」
   - 「打开 Chrome」
   - 「把这张照片放到电脑上看」
   - 「回家模式」（打开常用程序 + 调音量 + 放音乐等组合动作）
   - 「今天做了什么都记下来」
2. 执行器先给出计划，再逐步执行；语音识别失败时可以用首页的**文字输入**兜底。
3. **不可逆动作（发送、删除、打印、关机等）必须确认**后才执行；确认按钮会写清「将发生什么、影响谁、能否撤销」。
4. 每次执行写入审计账本，可在「今日」或审计页查看。
5. 识别/执行结束后，电脑会用中文 TTS 读出回复（可在设置页关闭「语音回复播报」）。

## 6. 设备页：同 WiFi 自动发现，一键绑定

- 顶部「刷新」可重新发现设备；
- 页面提示「同一 WiFi 自动发现；点『使用这台』即完成绑定，无需扫码」；
- 设备卡显示名称 / 平台 / 在线状态 / 已绑定状态：未绑定显示「**使用这台**」（一键绑定），已绑定显示「**移除**」（一键解绑）；
- 每张设备卡可带一键动作（来自设备能力，如打开程序 / 调音量 / 场景等）；
- 旧的扫码 / 6 位配对码流程已不在主流程；需要时可从托盘「打开完整控制台（旧版）」进入互联页。

## 7. 今日页：时间线与每日总结

- **「现在总结」按钮**：立即生成今天的总结与日记（不必等 23:00）；
- **总结卡**：显示 provider（DeepSeek 或本地降级）与生成时间，正文为 Markdown——「今天做了什么 / 明天要做什么 / 日记」；
- **语音记录** 列：当天语音转写，可点「刷新」；
- **屏幕文字** 列：当天本地 OCR 记录（含视频标题/字幕等）；
- 每天 **23:00** 自动生成；错过（如电脑关机）会在下次启动时补跑；历史内容在 `data/voice/diary/YYYY-MM-DD.md`。

## 8. 设置页

| 字段 | 说明 |
|---|---|
| 操作令牌 | 中枢 `operatorToken`（桌面程序会自动读取，可手动改；点「读取」刷新） |
| 常驻语音监听 | 开关；关闭后需手动点麦克风或输入文字命令 |
| 唤醒词（逗号分隔） | 默认「榫卯,小榫」 |
| 语音回复播报 | 电脑 TTS 朗读回复开关 |
| 每晚总结时间 | 默认 23:00 |
| 记录保留天数 | 语音/屏幕记录保留天数（默认 30） |
| 屏幕采集间隔（秒） | 默认 60；重启采集后生效 |
| 读取 / 保存到中枢 / 诊断 | 读取配置、保存设置、一键诊断连接与语音/采集状态 |

> 手机 App 的设置页另有：中枢地址、语音来源说明（默认送电脑识别）、屏幕采集授权/间隔/黑名单、本机记录清理等，见 §9。
## 9. 手机 APK 0.5

### 9.1 安装

- 文件：`public/download/tenon-android-0.5.0-debug.apk`（1.17 MB；debug 签名，仅体验用）。
- 传到手机安装（首次安装需允许「未知来源」）；**当前无真机实测**，安装/权限/采集流程以 App 内实际提示为准。

### 9.2 首次配置与权限

1. 手机与电脑连**同一 WiFi**；
2. 打开 App →「设置 → 中枢连接」填电脑地址（如 `http://192.168.x.x:7410`）与操作令牌（在电脑 `data/secrets.json` 的 `operatorToken`，或桌面程序设置页可复制）；
3. 允许 **麦克风**（RECORD_AUDIO）权限 → 用于「录音送电脑识别」；
4. 允许 **通知** 权限 → 语音管家/采集状态常驻提示；
5. 屏幕采集需在设置页点「授权并开启采集」，在系统弹窗里确认「共享屏幕」（MediaProjection）；可随时暂停。

### 9.3 手机功能

- **首页**：大麦克风（录音 → 送电脑识别 → 执行 → 回复，含「确认执行」闭环）、最近一句单行字幕、今日摘要；
- **设备**：自动列出电脑发现的设备，一键「使用这台」绑定/移除，每台最多 3 个一键动作；
- **今日**：今日语音/屏幕条数与最近总结；
- **设置**：中枢地址/令牌、语音管家、屏幕采集（开关/间隔/黑名单）、本机、关于/隐私。

## 10. 隐私与数据

| 数据 | 位置 | 是否上传 |
|---|---|---|
| 语音音频/转写 | `data/voice/`（转写按天 `data/voice/transcripts/YYYY-MM-DD.jsonl`） | 音频**不上传**；唤醒后的命令文本会发 DeepSeek（可关/无 key 本地降级） |
| 屏幕文字 | `data/voice/screen/YYYY-MM-DD.jsonl`、`data/screen/` 截图备份 | 只存本机，不上传 |
| 每日总结/日记 | `data/voice/diary/YYYY-MM-DD.md` | 生成时会把当天文本发给 DeepSeek；可关 |
| 操作令牌 | `data/secrets.json`（`operatorToken`） | 只在本机使用，勿外传/勿提交 |
| 桌面日志 | `logs/desktop.log` | 仅本机 |

- 屏幕采集是**本地系统 OCR**（Windows.Media.Ocr），不是大模型，不联网；
- 数据默认在程序目录 `data/`（单文件便携版首次运行若程序目录不可写，会使用 Windows 用户数据目录；托盘「打开数据目录」可打开）；
- 每日总结/日记：`data/voice/diary/YYYY-MM-DD.md`。
- 隐私开关：托盘/设置页可暂停语音监听与屏幕采集；也可在设置里关闭每日总结。

## 11. 常见问题（FAQ）

**Q：语音没反应？**
1. 看首页状态行是否「聆听中」；托盘菜单是否点了「暂停语音监听」；
2. 检查 Windows 麦克风权限（设置 → 隐私 → 麦克风）与默认输入设备；
3. 说话前先说唤醒词「榫卯」，或直接点麦克风按钮开始一次录音；
4. 识别服务异常时，用首页文字输入兜底（不阻塞其它功能）。

**Q：字幕不动 / 一直显示旧内容？**
1. 首页字幕只显示最近一句；停止说话后会停顿；
2. 检查是否暂停了监听；网络异常时页面会提示；
3. 手机 `/m/live` 若两行重复，属旧版本客户端问题，v0.5 已修复为单行。

**Q：屏幕采集暂停了 / 没有新内容？**
1. 托盘菜单或设置页看「屏幕采集」开关；
2. 屏幕无变化时不会重复记录（变化才抓，电脑默认 60 秒检查一次）；
3. 前台应用在黑名单里也不会记录；
4. 需要恢复时托盘点「开启屏幕采集」，或删除暂停标记 `data/voice/screen.pause`。

**Q：令牌在哪？**
1. 桌面程序「设置 → 中枢连接」可查看/复制；
2. 或看仓库 `data/secrets.json` 的 `operatorToken`；
3. 手机 App 的「设置 → 中枢连接」里填写同一个令牌。

**Q：关闭窗口后还在录音/采集？**
正常——关闭窗口只是收到托盘。要完全停止：托盘「退出榫卯」，或先暂停监听/采集。

**Q：手机连不上电脑？**
1. 同一 WiFi；电脑防火墙放行 7410；
2. 手机设置页的中枢地址是否为电脑实际局域网 IP（`http://电脑IP:7410`）；
3. 令牌是否正确（401 时 App 会提示）；
4. 设备页点「刷新」重新发现。

**Q：每日总结没生成？**
1. 默认 23:00 自动生成，需要电脑当时开着；错过会在下次启动补跑；
2. 可点「现在总结」立即生成；
3. 未配置 DeepSeek key 时会本地降级生成并标注原因。

**Q：没有 DeepSeek key 还能用吗？**
能。语音识别、屏幕 OCR、程序/命令执行、设备控制都在本地；执行器与每日总结降级为本地规则/本地模型，界面明确标注，不假装成功。

## 12. 已知边界（不吹）

- **手机真机未实测**：APK 0.5 只完成构建 + lint + 静态校验；安装、录音、屏幕授权需在真机确认。
- **单文件便携版**：桌面壳与本地服务已打包（双击即启动），但本地语音识别（FunASR）与屏幕 OCR 的 worker 仍依赖本机 Python 3 环境；卸载程序后 `data/` 数据需手动清理。
- **手机离线 ASR = P1/未实现**：手机录音一律送电脑识别；设置页已标注。
- **手机黑名单**：本版随上报携带应用黑名单字段，由电脑端过滤；手机端识别前台应用需额外系统权限（P1）。
- **屏幕采集需要系统授权**：Windows 若缺少 OCR 语言包/运行库，屏幕文字功能会降级并提示，不影响语音与执行。
- **不可逆动作必须确认**：打印、发送、删除、关机等不会静默执行。
- 局域网内使用明文 HTTP（设计如此，仅限可信内网）；正式对外分发前应移除体验用默认令牌。
