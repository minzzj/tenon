## 1. 一句话

**一台小软件，调动家里所有设备与所有程序：说一句（也可以语音）让 AI 调度不同设备上的不同程序；手机往前一倾，正在看的内容就滑到电脑大屏上。**

面向**家庭、个人与小团队**三种情况，不是企业系统。

## 1.1 主线定位：消费级 vs 企业可选

| 维度 | 消费级主线（默认） | 企业可选插件（附录 A） |
|---|---|---|
| 用户 | 家庭 / 个人 / 小团队 | 有合规要求的组织（额外开启） |
| 核心界面 | 超级终端首页、互联、素材、中转站、场景 | 企业控制台（角色/审批/审计保留期） |
| 语言 | 家 / 家人 / 我的设备 / 程序 | 组织 / 成员 / 审批 / 数据域 |
| 计费与部署 | 本地/局域网，零外联可用 | 私有化部署 + 合规导出 |
| 关系 | 默认交付 | **可按需关闭；关闭后不影响消费级体验** |

## 2. 与 v0.1.0 的关系

v0.1.0（2026-10-25 交付）解决「设备 / 软件 / AI 的可查任务链」：追加式事件账本、影响预览、消息回执、上线体检、审计导出，并用 146 条单元测试与真实浏览器验收留下证据。

v2 不推翻这些，而是在**同一账本与任务引擎**上增加消费级体验：

1. **互联**：发现、配对、文件互传、剪贴板/通知；
2. **素材中心**：归集、去重、OCR 搜索、标签、谱系、中转站；
3. **场景控制**：把多个动作编排成可确认、可审计的场景；
4. **超级终端**（v2.1）：一句话/语音调动设备与程序、手机一倾上大屏。

数据仍默认留在本机或局域网；事件只追加、可审计；不可逆动作仍要逐次确认。企业能力以可选插件提供（附录 A）。

## 4. v2-P0 功能规格（已实现）

> 下列 v2-P0 功能已实现并有证据：隔离实例验收 9/9（2026-10-25 14:11）；各模块自带 node:test 共 71 条通过（link 13 / assets 13 / things 9 / enterprise 17 / desktop 19）。v2.1 超级终端入口见 [产品愿景 v2.1](产品愿景-v2.1-消费级超级终端.md) §5。

### 4.1 发现与配对

- **目标**：同一 WiFi 下手机与电脑互相发现，配对一次后长期可信。
- **功能点**：局域网 UDP 广播自动发现（默认端口 7413）；6 位配对码 + 扫码（`tenon://pair?host=IP:PORT&code=XXXX&fp=...`）；信任设备列表可撤销；拔掉公网仍可用。
- **实测**：配对/信任/撤销链路通过模块测试与隔离实例验收（UDP 发现约 630ms）；「≤10s」为验收线。

### 4.2 文件互传

- **功能点**：1MB 分块、断点续传、SHA-256 校验、批量与任意大小；记录 bytes/ms/speedBps。
- **实测**：本机两进程真实 UDP + HTTP，8MB 分块传输 **39–46 MB/s**（多次），断点续传与 SHA-256 校验通过；1GB 单次与手机真机未归档。

### 4.3 剪贴板 / 链接互传

- **功能点**：手机复制 → 电脑粘贴；桌面复制 → 手机通知/剪贴板可见；需显式开启，可随时关闭。
- **实测**：电脑端剪贴板双向读写经 PowerShell 回读一致；≤2s 计时与 Android 真机未归档。

### 4.4 Android 原生 App

- **功能点**：配对、传文件、剪贴板同步、通知镜像、素材上传/浏览、分享目标、设置页。
- **技术**：Kotlin + Gradle；包名 `com.minzzj.tenon`；minSdk 26 / targetSdk 34；局域网 HTTP + UDP 发现；前台服务保活。
- **实测**：`assembleDebug` BUILD SUCCESSFUL（44s），APK **1,159,245 B（1.11 MB）**，debug 签名，lint 0 error / 34 warning；**无真机/模拟器 → 未做安装实测**（步骤见仓库 `android/README.md`）。v2.1 将增加倾斜甩屏与语音指令并重新构建。
- **补充**：手机网页（PWA）保留为「零安装备用入口」，iOS 二期用它做手动互传。

### 4.5 素材中心

- **功能点**：电脑文件夹扫描 + 手机分享/上传归集；SHA-256 去重；缩略图（sharp，320/640 webp）；OCR（tesseract.js chi_sim+eng，异步队列，失败不影响入库）；按文件名/OCR/类型/设备/时间搜索；标签；素材详情（来源设备/路径/哈希/引用）；谱系事件（ingest/tag/share/remove）；超级中转站。
- **实测**：500 条索引 635KB、搜索毫秒级、同图去重；OCR 真实召回「桦 卯 样品 01…」（confidence 51，459ms 热缓存）；500 张 ≤60s 单点计时未单独归档。

### 4.6 场景控制

- **功能点**：物模型（能力 → 属性/动作/事件）；3 个真实场景：打印素材、投屏照片到电脑、备份到 NAS/文件夹；场景新建/执行；不可逆确认；`scene.defined` / `scene.ran` 审计。
- **实测**：3 个场景真实执行——备份真拷贝且 SHA-256 一致；打印未确认账本零新增、确认后 printer.mock 真实出 outbox；投屏调用 opener、降级留痕；审计事件完整（9/9 单测）。

### 4.7 企业版基础（可选插件，非主线）

- **功能点**：角色（管理员/成员/访客）、动作白名单、越权留痕、不可逆审批开关、审计保留期可配、私有化部署、身份适配器接口 + mock。
- **实测**：17/17 单测 + 37 项 HTTP E2E + 21 项 v2 集成通过。
- **说明**：企业版是**可选插件形态**，家庭/个人/小团队成员默认不需要它；边界见附录 A。

### 4.8 家庭版基础

- **功能点**：家庭成员邀请、家庭相册共享、访客只读/限时（v2-P0 基础）。
- **验收**：家庭成员可见共享相册，访客只能看、到期失效（后续真机/多账号场景补充）。

## 7. 技术路线与架构

### 7.1 复用 v0.1.0

事件账本（唯一事实来源）、状态重放、任务引擎（草案/确认/执行/回执）、影响预览、通道、体检、审计导出、HTTP API + SSE。

### 7.2 已实现模块（v2-P0）

| 模块 | 目录 | 职责 |
|---|---|---|
| 连接层 | `server/lib/link/` | UDP 发现、配对/信任设备、分块断点传输 + SHA-256、剪贴板、通知 |
| 素材中心 | `server/lib/assets/` | 哈希去重、缩略图、OCR、索引与搜索、标签、谱系、中转站 |
| 物模型与场景 | `server/lib/things/` | 能力→属性/动作/事件、场景 CRUD 与执行（复用任务引擎） |
| 企业控制面（可选插件） | `server/lib/enterprise/` | 成员/角色、动作白名单、审批、审计保留期、身份适配器（mock） |
| 电脑端扩展 | `node-agent/` | 文件收发、剪贴板读写、通知、素材扫描、受控动作 |
| Android App | `android/` | 原生 App（发现/配对/传文件/剪贴板/通知/素材/分享目标） |
| Web / 手机页面 | `public/` | `#/link #/assets #/basket #/scenes #/enterprise`；`/m/link`、`/m/assets` |

### 7.3 v2.1 新增（进行中）

| 模块 | 目录 | 职责 |
|---|---|---|
| 超级终端服务 | `server/lib/super/` | 设备/程序目录、AI 语音意图、计划→任务执行、流转 handoff |
| 超级终端首页与接收页 | `public/` | `#/super` 首页、`#/handoff` 接收页、语音与计划步骤渲染 |
| 桌面动作能力 | `node-agent/` | `app.launch`、`url.open`、`media.show`、`handoff.show`、`app.list` |
| 手机甩屏 | `public/m` + `android/` | 甩到电脑按钮、倾斜手势、语音指令 |

### 7.4 依赖策略

允许可选依赖以追求效果：`sharp`、`tesseract.js`、按需 `ffmpeg`、P1 的向量/视觉模型；**核心服务仍可离线私有化部署**，依赖清单随包锁定。

### 7.5 数据与隐私

- 数据目录：`data/link/`、`data/assets/`、`data/basket/`、`data/things/`、`data/enterprise/`。
- 默认仅本机/局域网直连，不依赖厂商云；剪贴板与通知监听需用户显式授权，可随时关闭。
- 素材与操作记录进事件账本，可导出审计；删除素材写 `asset.removed`，不做静默删除。

## 8. 非目标

- 不做企业管理系统/审批流产品；不做云端 SaaS、多租户；不做跨企业数据交换。
- 不做 Matter/Thread 配网；不做投屏协议私有实现军备竞赛（Miracast/AirPlay 私有实现）。
- 不做 iOS 后台控制（iOS 二期只做手动互传）。
- 不做万能远程桌面 / GUI 点击机器人；不可逆动作始终逐次确认。

## 9. 风险与前置条件

| 项 | 说明 | 未满足时怎么写 |
|---|---|---|
| Android 真机 | 安装实测需要一台 Android 手机（USB 调试/同 WiFi）；没有则用模拟器 | 标「构建交付，未真机实测」 |
| 手势/语音权限 | `deviceorientation` 需 https 或 localhost；语音识别需麦克风授权、部分浏览器不支持 | 降级文字并明确提示 |
| OCR/视觉依赖 | 模型体积与机器性能；语言包需联网首次下载 | 记录依赖体积与降级行为 |
| 1GB 传输 | 速度受 WiFi 质量与磁盘影响；记录本机实测值，不承诺通用速度 | 附实测环境与速度口径 |

## 附录 A. 企业版（可选插件形态，非主线）

> 本附录只给需要合规的组织看。家庭/个人/小团队用户可以完全忽略；不开启插件时，产品不会出现「组织/审批/角色/保留期」等概念。

- **定位**：在消费级主线上**额外开启**的控制面插件，不是独立产品，也不是默认首页。
- **已实现（v2-P0）**：成员与角色（管理员/成员/访客）、按角色动作白名单、越权留痕、不可逆动作审批开关、审计保留期 7/30/180 可配、私有化部署、身份适配器接口 + mock（企业微信/钉钉/SSO 真实对接需企业凭据，P1）。
- **界面**：开启后出现「企业控制台」（`#/enterprise`）；关闭插件后入口隐藏，消费级功能不受影响。
- **证据**：企业模块 17/17 单测 + 37 项 HTTP E2E + 21 项 v2 集成通过；隔离实例验收 C7 通过。
- **边界**：不做跨企业数据交换；不做多租户 SaaS；真机房高可用未验证；真实身份集成凭据由企业提供。
- **设计原则**：企业能力只加「控制」不改变消费级体验；所有控制动作仍写入同一事件账本。
